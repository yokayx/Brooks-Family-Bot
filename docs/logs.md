# Логи сервера

Ког `bot/cogs/logs.py`. Порт кога из KillaBot: без медиа-хранилища и без своей
таблицы инвайтов (приглашение считаем по кэшу использований в памяти).

## Куда что пишем

Значения — константы в `bot/config.py`. Сейчас стоят `0`: **ID каналов надо
подставить**, когда руководство их выдаст. `0` = «канал не настроен», такой лог
молча пропускается (бот не падает и ничего не шлёт).

| Константа | Что логирует |
|-----------|--------------|
| `LOG_TEXT_CHANNEL_ID` | удаление и правка сообщений |
| `LOG_INVITE_CHANNEL_ID` | зашёл / вышел, по какой ссылке и кто пригласил |
| `LOG_MEMBER_CHANNEL_ID` | выдача/снятие ролей, смена username |
| `LOG_MODERATION_CHANNEL_ID` | бан, разбан, кик, тайм-аут, смена ника |
| `LOG_VOICE_CHANNEL_ID` | вход/выход/переход в войсе, мут и звук |
| `LOG_SERVER_CHANNEL_ID` | создание/удаление каналов, смена прав доступа |
| `LOG_AUDIT_CHANNEL_ID` | поллинг аудит-лога (каждые 30 с, дедуп по id записи) |

## Интенты

Боту нужны:

- `guilds`, `members`, `messages` — уже включены;
- `voice_states` — добавлен в `bot/main.py`, привилегий не требует;
- `message_content` — **привилегированный**. Без него Discord не присылает текст
  сообщений, и в логах удаления/правки вместо текста будет `—`. Чтобы логи
  текста работали: отметить «Message Content Intent» в Discord Developer Portal
  и поднять `MESSAGE_CONTENT_INTENT=true` в `.env` (иначе бот не залогинится с
  ошибкой 4014).

## Ограничения

- Кэш сообщений — последние 10 000, кэш аудита — 1 000 id; при перезапуске
  сообщения, отправленные до него, логируются без текста.
- Кик от модератора отличаем от добровольного выхода по аудит-логу за последние
  10 с (нужно право «Просмотр журнала аудита»).
- Логи пишутся только по нашему серверу (определяем по `ROSTER_CHANNEL_ID`).
