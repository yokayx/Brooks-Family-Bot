# Логи сервера

Ког `bot/cogs/logs.py` — порт кога из KillaBot на структуру Brooks. Все логи
уходят **эмбедами**, по категориям.

## Категории и каналы

Категория -> константа в `bot/config.py`. `0` = «канал не настроен», такой лог
молча пропускается.

| Категория | Константа | Что логирует |
|-----------|-----------|--------------|
| `moderation` | `LOG_MODERATION_CHANNEL_ID` = `1553289349653598319` | кик, бан, тайм-аут, мьют, варны (свои события) |
| `voice` | `LOG_VOICE_CHANNEL_ID` = `1553289200244232252` | войс: вход, выход, переход, трибуны (открыта/закрыта/тема) |
| `text` | `LOG_TEXT_CHANNEL_ID` = `1553289165179985960` | удаление (с вложениями), правка (дифф), массовая очистка |
| `member` | `LOG_MEMBER_CHANNEL_ID` = `1553289245605634128` | роли, никнейм, аватарка |
| `invite` | `LOG_INVITE_CHANNEL_ID` = `1553289264349839371` | вход/выход участника, создание и удаление инвайтов |
| `server` | `LOG_SERVER_CHANNEL_ID` = `1553289301389877268` | бот добавлен на сервер, массовая очистка сообщений |
| `audit` | `LOG_AUDIT_CHANNEL_ID` = `1553289418528522270` | **дубль всех логов** (кроме самой категории audit) |
| `bot-live` | `LOG_BOT_LIVE_CHANNEL_ID` = `1553289439135006841` | «живая консоль»: трансляция журнала Python |

## Инвайт-трекер

- При старте ког кэширует инвайты и Vanity URL.
- На входе участника определяет, по какой ссылке он пришёл и кто пригласил
  (в т.ч. Vanity URL), показывает возраст аккаунта, сколько раз человек был на
  сервере и сколько раз выходил (`member_stats`).
- Кик и бан отличаются от добровольного выхода по аудит-логу за последние 5 сек.

## Вложения

`on_message` заранее скачивает вложения в `data/log_attachments` (до 25 МБ,
картинки сжимаются Pillow, если он установлен). Когда сообщение удалят, файлы
прикрепляются к логу — ссылка к тому моменту уже мертва. Фоновая задача раз в
2 часа удаляет файлы старше 24 часов.

## Live-консоль

Категория `bot-live`: к корневому логгеру Python цепляется
`DiscordLoggingHandler`, который пачками по 8 записей раз в 2 секунды шлёт
журнал в канал. Очередь ограничена 500 записями (при флуде старое
отбрасывается).

## Интенты и права

- `guilds`, `members`, `messages`, `voice_states` — включены в `bot/main.py`.
- `message_content` — **привилегированный**. Без него в логах удаления/правки
  вместо текста будет пусто. Нужно отметить «Message Content Intent» в Discord
  Developer Portal и поднять `MESSAGE_CONTENT_INTENT=true` в `.env`.
- Право **«Управление сервером»** — читать инвайты.
- Право **«Просмотр журнала аудита»** — определять, кто удалил/кикнул/забанил.
