# Что можно взять снаружи по GTA5RP

Официального API у проекта **нет**. Тех.админы на форуме это прямо закрыли:

- [API для разработчиков](https://forum.gta5rp.com/threads/api-dlya-razrabotchikov.2492604/) — Ward: «Нет.»
- [Api GTA V RP](https://forum.gta5rp.com/threads/api-gta-v-rp.3151143/) — Shane Diesel: «У нас нет такого функционала»

Личный кабинет `gta5rp.com`, форум, вики, донат — только через логин. Публичных JSON по персонажам, семьям, точкам и логам ВЗП у проекта нет.

## Онлайн Richman — да, стабильно

Игра крутится на RageMP, список серверов публичный.

### 1. RageMP masterlist (ближе к «железу»)

`GET https://cdn.rage.mp/master`

Ключ: `richman.gta5rp.com:22005`

Поля: `name`, `players`, `peak`, `maxplayers`, `gamemode`, `url`, `lang`.  
Нет ключа → сервер не в мастере (рестарт / техработы).  
Снимок: **627** игроков, peak **633**, max **5000**.

Минус: нет графика, нет `todayPeak` за календарный день, документ не версионирован.

### 2. gta5masterlist.ru (удобнее для бота)

Документация: https://gta5masterlist.com/api-docs  
База: `https://gta5masterlist.ru/api`  
Лимит: не чаще раза в 5 минут, non-commercial.

| Метод | Зачем |
|--------|--------|
| `GET /api/stats` | суммарный онлайн всего GTA5RP |
| `GET /api/servers` | все сервера, Richman в массиве `gta5rp` |
| `GET /api/servers/gta5rp/8` | Richman + график |
| `GET /api/chart-data?range=24h` | история проекта |

Richman = `serverId: 8`.

Снимок API:

```json
{
  "serverId": 8,
  "name": "Richman",
  "region": "ru",
  "currentOnline": 629,
  "maxPlayers": 2000,
  "status": true,
  "todayPeak": 629,
  "allTimePeak": 2105
}
```

`maxPlayers` у мониторингов расходится (2000 vs 5000 у RageMP) — для эмбеда брать `currentOnline` + `status`, слоты — с оговоркой.

Для бота семьи лучше **masterlist `/api/servers/gta5rp/8`**: онлайн, пик дня, график, статус.

## Результаты VЗП — официально нельзя

ВЗП = война семей / предприятия / точки влияния. Правила: [форум](https://forum.gta5rp.com/threads/pravila-voiny-semei-tochki-vlijanija.3359369/).

У проекта это живёт **в игре** (`M` → Война семей) и в **Family War Discord** сервера. Наружу не отдаётся:

- кто держит точку;
- лог забива / счёт боя;
- состав вышедших;
- репутация семьи;
- кто из семьи онлайн в мире.

Парсить кабинет/форум с аккаунта — ToS-серая зона и ломается на любом антиботе.

## Откуда vzp-launcher.pro берёт ВЗП

Коротко: **не из API GTA5RP.** Первоисточник — **сам игровой клиент** (меню `M → Война семей` и инстанс боя). Лаунчер это снимает у тех, у кого крутится их Windows-оверлей, и складывает к себе на сайт.

Официального HTTP у проекта по-прежнему нет. В [оферте](https://vzp-launcher.pro/terms) прямо: сервис **не** продукт GTA 5 RP.

### Что именно они видят из игры

1. **Меню войны семей** — кто напал, кто держит точку, сервер, территория, карта, слоты, ID организации.
   На [точках семей](https://vzp-launcher.pro/statistics/family-points) висят игровые id (`BEIFONG #8669`) и число предприятий. На Downtown сумма точек = 100 — это полная карта сервера, не ручной ввод.
2. **HUD инстанса боя** — живой счёт, килл-лог, урон, точность, хедшоты, кто вышел.
   Этого нет ни в Family War Discord, ни на форуме. У [Takashi_Brooks](https://vzp-launcher.pro/player/129292) уже точность 26% и HS 5.6% — такие цифры бывают только в бою.
3. **Привязка ника** — отдельно и вручную: заявка со скрином. Стата прилетает по игровому нику, Discord нужен для аккаунта на сайте, не как источник боёв.

### Почему это не «слив API проекта»

- FAQ: в рейтинг идут войны, которые **«попали в лаунчер»**; в тикетах — «не засчитали войну». Нет клиента на бою → матча нет.
- Живые 0:0 появляются в момент забива, счёт тикает во время боя — Discord так не обновляют.
- Оверлей специально садится поверх GTA в режиме «окно без рамки».

Итог: первоисточник = **RageMP-клиент GTA5RP у игрока**. Официальной трубы GTA5RP нет.

## Итого для бота Brooks

| Нужно | Источник | Надёжность |
|--------|----------|------------|
| Онлайн Richman, пик, ап/даун | `gta5masterlist.ru/api/servers/gta5rp/8` | высокая |
| Онлайн «как в лаунчере Rage» | `cdn.rage.mp/master` | высокая |
| Официальные логи ВЗП / точки | нет | — |
| Счёт боёв Brooks | `vzp-launcher.pro/api/wars` + карточка [176611](https://vzp-gta5rp.com/stats/families/176611) | средняя, не GTA5RP |
| Кто из состава онлайн в игре | нет | — |

Ког `bot/cogs/vzp.py` постит **только новые доигранные** капты Brooks/Richman в канал `1552367826906521620`. Первый запуск историю не спамит.

Как ищет:

1. `GET /api/wars?limit=100&page=N` — **несколько страниц** (`VZP_FETCH_PAGES`, ≈8 часов эфира).
   Одна страница = 100 войн ≈ 2–3 часа всех серверов; Brooks играет 1–2 раза в день,
   так что на одной странице итог легко уезжает за окно.
2. Своя фильтрация: `server_name == RICHMAN` и Brooks в `attacker_name` / `defender_name`.
   Серверных фильтров у API нет: `search`, `status`, `server_name` в query игнорируются
   (проверено 26.09.2026 — меняется только `total`, выдача та же).
3. По каждому новому кандидату — `GET /api/wars/{id}` и решение **по деталям**:
   в списке статус иногда протухает (`active` у доигранного боя, `0:0`, `ended_at: null`),
   а в деталях тот же бой уже `finished` со счётом и составом.
4. Опрос раз в `VZP_POLL_SECONDS` (300 с), 3 попытки на запрос с паузой;
   заголовки — «браузерные»: без них сайт отдаёт 403/429.

`/vzp` (руководство) — ручной прогон и диагностика: сколько войн просмотрено,
сколько Brooks/Richman нашлось, что отправлено и последняя ошибка запроса.
