## Как подаётся заявка

Модалки больше нет: выбрал состав в списке — **сразу открывается тикет** в
категории открытых заявок. Внутри:

0. эмбед «Новая заявка · Main/VZP» с заявителем, номером тикета и списком
   вопросов формы;
0. бот пишет `**Вопрос N из M:** …` и ждёт ответ сообщением в канале тикета
   (`APPLICATION_ANSWER_TIMEOUT_SECONDS`, 30 минут на вопрос);
0. когда ответы собраны — эмбед «Анкета заполнена» (вопрос → ответ) и кнопка
   «Взять заявку» у рекрутера/руководства;
0. если заявитель молчит — бот пишет, что время вышло, тикет остаётся открытым.

## Панель управления

Панель публикуется **сама при старте бота** в канале `1553239900176908289`
(руководство), id сообщения в `bot_messages` (`control_panel`); удалили —
отправит заново. Отдельной команды для публикации нет.

Если Discord не показывает новые слэш-команды — `/синк` (руководство), он
принудительно пересинхронизирует дерево команд на сервере.

| Кнопка | Что делает |
|--------|-----------|
| Открыть набор Main / Закрыть набор Main | `application_kinds.main.is_open` |
| Открыть набор VZP / Закрыть набор VZP | `application_kinds.vzp.is_open` |
| Форма Main / Форма VZP | менеджер вопросов выбранного вида |

После смены статуса бот перерисовывает сообщение с меню заявок (`:on:`/`:off:`).
Закрытый набор: в списке заявок вместо формы — «Набор на этот состав сейчас
приостановлен».

ЧС нет: отклонение только с причиной, без роли и записи в чёрный список.

## Как работает

0. Меню заявок публикуется **само при старте бота**, без команд: описание двух
   составов, их требования, **статус набора** (`:on:` / `:off:`) и
   раскрывающийся список — всё одним **эмбедом**:

   - `Заявка на Young` — «Заполнить заявку в семью» → форма **Main**;
   - `Заявка на Test` — «Заполнить заявку в семью на VZP» → форма **VZP**.

   id сообщения хранится в `bot_messages` (`applications_menu`). При старте бот
   его перерисовывает; если сообщение удалили — отправляет новое в канал заявок.
   Текст обновляется с панели управления при смене статуса набора.
0. Формы — свои на каждый вид: `/настроить-форму вид: Main` и `вид: VZP`,
   до 5 активных вопросов на вид. Вопросы лежат в `application_questions.kind`.
   Вид заявки пишется в `tickets.kind` и виден в заголовке тикета.
1. Руководство: `/настроить-форму` — до 5 активных вопросов. `/отправить-кнопку-заявки` постит кнопку в канал заявок (живёт после рестарта).
2. Человек жмёт кнопку → модалка с вопросами → канал `заявка-{ник}` в категории открытых тикетов. Ответы в эмбеде + SQLite (`tickets.answers_json`).
3. Стафф берёт заявку. Кнопки: освободить, принять, отклонить.
4. **Принять:** роли Test + семейная; ЛС и сообщение в тикете (ник по форме `[Nick] | Имя`, день рождения); канал закрывается через 1 час (перенос в закрытые, у заявителя снимается доступ).
5. **Отклонить:** модалка с причиной → ЛС + сообщение в канале → сразу в закрытые.
6. После принятия: кнопки «Установить никнейм» и «Указать день рождения» (`17.05` / `17 мая` / `may 17`, таймзона не нужна). ДР пишется в `birthdays`.
